# 🚀 KMC EventHub - Service-Oriented Event Management System

🚀 KMC EventHub is a comprehensive, Service-Oriented Computing (SOC) platform designed specifically for the Kandy Municipal Council (KMC) to modernize city-wide event promotion, discovery, and community engagement. This application replaces fragmented, manual event scheduling with a secure, loosely coupled digital ecosystem featuring a high-performance backend API and an intuitive, public-facing web client application.

✨ Features 
🔒 **Role-Based Authorization**: Enforces strict security boundaries within the service layer, ensuring that only the verified original creator of an event is authorized to modify, update, or remove its details.
📅 **Comprehensive Event Management**: Enables authorized municipal organizers and verified external stakeholders to easily create, plan, and manage local public events.
👥 **Participant Registration**: Provides an automated, streamlined service enabling city residents to instantly register and secure spots for specific community events.
🔍 **Dynamic Event Discovery**: An advanced public search and multi-factor filtering module allowing users to instantly locate city events by Date, Type, or custom title keywords.
🌐 **Third-Party Interoperability**: Formatted with standardized JSON endpoints over HTTP, allowing external local businesses and community groups to integrate and sync their own private systems seamlessly with the central city hub.

🛠️ Technologies Used
💻 **C# / .NET Web API** (Core service layer architecture and backend business logic orchestration)
🗄️ **SQL Server** (Relational Database Management System hosting event records, users, and participant registrations)
🌐 **ASP.NET Client App** (Public-facing web platform consuming core API endpoints to render real-time event data)
🔧 **Microsoft Visual Studio** (Integrated Development Environment used for compilation, debugging, and service testing)
